# Study library

A readable companion to the portable [research dataset](../dist/data/collection.json). Last reviewed: 2026-11-05.

## Coverage

- 45 substantive practitioner studies.
- 158 source-work entries.
- 195 evidenced decisions and tradeoffs.
- 167 communication observations.
- 73 original exercises.
- 21 [cross-study comparisons](comparisons.md).
- 1 [discovery-only profiles](discovery.md), excluded from substantive counts.

The original Cosign lists contain more people than this study set. Nomination is not an award won or a ranking. Selection reflects the accessibility and specificity of public evidence, not professional merit. Full texts, selected sections, transcripts, publisher recaps, and previews are differentiated within each study.

## How to use these notes

Read the source before treating a summary as authority. Identify the choice, the rejected alternative, the constraint, and the missing evidence. Predict a decision before revealing it when possible. Then try a small exercise and record what would change your mind.

These files are generated from the normalized public dataset. Preserve source access, authorship, and limitations when editing the underlying research. Run `node scripts/build-collection.mjs` followed by `node scripts/build-study-notes.mjs` to refresh them.
