# Contributing

## Add a study

1. Confirm the practitioner's connection to the original public roster; preserve the nomination framing.
2. Select primary public work. Read actual content rather than search snippets when possible.
3. Record title, exact URL, date or date uncertainty, authorship, access scope, and a short original summary.
4. Identify decisions, alternatives, tradeoffs, evidence URLs, and limits. Label interpretation.
5. Explain a concrete communication technique using a linked example.
6. Propose an original exercise with a deliverable and evaluation criteria.
7. Keep all private information out of the dataset.
8. Rebuild the collection, validate it, run tests, and inspect the changed study in the browser.

## Correct a claim

Include the study ID, the current wording, the proposed correction, and a source. Prefer precise attribution and uncertainty over a more flattering story.

## Design principles

Readable before decorative. Source-first. Evidence beside claims. A visible distinction between observation, inference, and practice. Notebook content remains local. No tracking or unnecessary dependencies.
